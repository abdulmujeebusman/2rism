# 2rism

A static landing page for a travel/tourism site. It showcases popular destinations, hotels & restaurants, travel tips, and activities, with a hero section linking out to Google Earth's 3D globe.

## Features

- Responsive hero section with a search-style planner (location, activity, date, guests)
- Popular destinations, hotels & restaurants, travel tips, and activities sections
- Mobile nav toggle
- Smooth-scrolling anchor navigation between sections

## Tech stack

- HTML5
- CSS (compiled with [Tailwind CSS](https://tailwindcss.com/))
- Vanilla JavaScript

## Project structure

```
.
├── index.html          # Main page markup
├── css/
│   └── styles.css      # Compiled Tailwind styles + custom CSS
├── js/
│   └── script.js       # Nav toggle and smooth-scroll behavior
└── assets/
    └── images/         # Images, icons, and logos
```

## Getting started

This is a static site with no build step. Clone the repo and open `index.html` in a browser, or serve it locally:

```bash
npx serve .
```

Then visit the printed local URL in your browser.
